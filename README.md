# Project 2 - Model Readiness Assessment

This repository contains the starter files for Project 2 in **Data Engineering for AI Applications**.

## Project Overview

This project uses an instructional version of the UCI Bank Marketing dataset. The dataset describes a Portuguese bank's telephone marketing campaigns. The associated classification task is to predict whether a client will subscribe to a term deposit.

Students will explore the dataset and assess its readiness for the supplied modeling workflow. Refer to Blackboard for the complete project instructions, requirements, due date, and grading information.

## Getting Started

1. Clone your Project 2 repository to your computer.
2. Open the repository folder in VS Code.
3. Read `DATA_SOURCE.md` before analyzing the dataset.
4. Open `week2_project_model_readiness.ipynb`.
5. Select the `.venv` virtual environment you created in Week 1 as the notebook kernel.
6. Follow the project directions in Blackboard and the prompts in the notebook.



Save your work and commit and push your changes to GitHub regularly.
